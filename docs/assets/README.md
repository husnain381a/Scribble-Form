# Scribble brand and screenshots

- `banner.svg`: repository header, 1200 × 520.
- `logo.svg`: transparent horizontal wordmark.
- `logo-mark.svg`: square feather mark.
- `landing.jpg`: the application's landing page.
- `responses.jpg`: a response detail view using invented demonstration data.

SVG lettering is outlined so it renders consistently without downloading fonts. The artwork uses Scribble's existing Caveat and DM Sans typography and its paper, ink, mustard, sage, and coral palette. The feather mark matches the app icon. These assets are covered by the project's license; see [NOTICE.md](../../NOTICE.md) for font and dependency credits.

Keep the artwork's proportions and readable contrast when reusing it. Do not use the project's name or artwork to imply an endorsement of a separate hosted service. Never replace demonstration screenshots with real respondent data or private instance details.
